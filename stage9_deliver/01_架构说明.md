# 01 架构说明（骨架，S8 填完）

## 一张图

```
image ──► SigLIP-base-384（冻结，576 patch）
              │
              ▼
        连接器（三选一）
        mlp 576 / resampler 64 / pixelshuffle 144
              │
              ▼
   [v1 … vNv] + [prompt tokens]  ──►  Qwen2.5-0.5B（LoRA r=16）
                                          │
                                          ▼
                                      answer + logprob
```

## 为什么是"前缀拼接"而不是占位符

占位符要处理 tokenizer 的 special token 边界；前缀拼接没有这个问题，
代价是不能交错图文。对以单图问答为主的项目，这个取舍是划算的。

## 数据流

`Sample`（jsonl）→ `SynthSFT` → `collate` → `Batch` → `PicoVLM.forward`
labels 规则：视觉 -100 / prompt -100 / 只有 answer 参与 loss。
