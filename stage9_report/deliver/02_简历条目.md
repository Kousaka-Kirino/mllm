## 主条目（3 条，压缩到 3 行）

- **PicoVLM｜8GB 单卡训 5.89 亿参数图表问答模型**：SigLIP-base（冻结，93M）+
  Qwen2.5-0.5B + LoRA（r=8），仅训练 **3.38M 参数**（connector 2.30M + LoRA 1.08M）；
  单图 **196ms / 1.4GB**，SFT 峰值 **3.8GB**，全程在 RTX 4060 Laptop 8GB 上完成。
- **用 2×2 受控实验分离"看不见"与"不看图"**：自建 636 个 family 的合成图表数据，
  字形像素按渲染后实测（median 6.0px，范围 3.0–9.0px）、阈值预注册；
  SFT 后 **一致格 0.950 / 1.000，冲突格 0.000 / 0.100**，prior_effect **+0.950**
  （family 聚类 bootstrap 95% CI **[0.833, 1.000]**）。
- **证明失败来自先验而非分辨率**：把图换成同数据集另一张图，80 对里各只有 1 对翻转
  （overall 0.512 vs 0.512，**McNemar p = 1.0**）；局部放大实验 salient 0.542 vs
  full 0.583（**−0.042**，不显著）；换画风（衬线字体/四边框/虚线网格）后 **0.000**，
  97.5% 的样本直接不出话——失败层次是先验 → 画风 → 分辨率。
- **规模可复现**：同一 checkpoint 搬到 15.6× 测试集（312 family/格）复现，
  **0.968 / 0.029 / 0.952 / 0.051**，prior_effect **+0.939**（CI **[0.910, 0.966]**），
  acuity_effect **+0.016**（CI 跨 0）。

## 负结论（单独一条，写在简历里比"涨点"值钱）

- **GRPO 在 8GB 小模型上组内几乎无信号**：G=2–4、12 条 rollout 中 **5/6 组奖励全同**
  （全 0 或全 1）→ 优势恒为 0；同时给出 RFT 对照与"为什么这个规模下 PPO 风格更新退化为
  加权 SFT"的机制分析。视觉记忆的页内召回 recall@1 仅 **0.083**（[0.023, 0.258]），
  定位为"冻结特征 + 平均池化丢失区分性信息"。
