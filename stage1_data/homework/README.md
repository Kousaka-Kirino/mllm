# S1 作业提交说明

三道题，两道必做一道选做。交作业的方式：

1. 在 `stage1_data/homework/` 下把 `hw*.py` 里的 `TODO` 写完；
2. 跑 `python -m pytest tests/test_hw_stage1.py -q` 自测（测试文件自己写，
   或者照 `HW1_提示.md` 里给的断言）；
3. 把关键输出贴到 `homework/HW_report.md`（模板见下）。

## 提交物

| 文件 | 内容 |
|---|---|
| `hw1_family_split.py` | family 划分实现 |
| `hw2_acuity_probe.py` | 着墨高度测量实现 |
| `HW_report.md` | 三道题的运行结果 + 你观察到的现象 |

## HW_report.md 模板

```markdown
## HW1 family 划分
- 输入 120 个 family，比例 0.8/0.1/0.05/0.05
- 实际：96/12/6/6，最大误差 0.4%
- 同 seed 两次运行一致：是

## HW2 着墨高度
- 阈值 200 时，字号 0.55 测得 9px（渲染尺度），1.45 测得 27px
- 阈值改成 180 时，0.55 变成 10px：小字号对阈值更敏感
- 换算到 384 输入尺度：3.0px vs 9.0px

## HW3 抽查
- 抽了 10 条，9 条一致；1 条我把 "类别 B" 数成了 3 而标注是 2（我看错图）
```

## 评分标准（自测用）

- 能跑通：60 分
- 边界条件正确（空输入、比例不能整除、单 family）：80 分
- 报告里写了"我发现了什么"而不只是"结果是什么"：90 分以上

## 常见坑

- `int()` 截断导致比例加起来不等于总数（用最大余数法，见提示）；
- 用 `random.shuffle` 而不用固定 seed 的 `np.random.default_rng`，
  结果不可复现；
- 测着墨高度时把抗锯齿的浅灰像素也算成"有墨"，导致小字号系统性偏大。
